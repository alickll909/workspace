# zai-mcp-server

综合 MCP 服务器，提供多模态分析工具集。

## 用途

- **ui-to-artifact**：UI 截图转代码，将设计稿/截图转换为前端代码
- **text-extraction**：图片文字提取
- **error-diagnosis**：错误诊断分析
- **diagram-analysis**：图表/流程图分析
- **data-viz-analysis**：数据可视化分析
- **ui-diff-check**：UI 差异比对
- **general-image-analysis**：通用图片分析
- **video-analysis**：视频内容分析

## 使用方式

```bash
zai-mcp-server
```

## 前置要求

- 已安装 `zai-mcp-server`
