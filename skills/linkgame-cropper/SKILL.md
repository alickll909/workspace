# 连连看牌面裁剪 Skill

对指定文件夹内的 PNG/JPG 图片进行批量裁剪，生成 64×64、128×128、192×192 三种尺寸，文件名按 `原名称64@1x.ext`、`原名称64@2x.ext`、`原名称64@3x.ext` 命名。

> 即 `abc.png` → `abc64@1x.png`(64×64) / `abc64@2x.png`(128×128) / `abc64@3x.png`(192×192)

## 前置条件

- macOS 系统
- 依赖 ImageMagick（脚本会自动检测并在需要时通过 Homebrew 安装）

## 执行步骤

1. **确认目标文件夹**
   - 如果用户不指定，默认使用当前工作目录
   - 确认文件夹内有 `.png` / `.jpg` 文件（支持大小写后缀）

2. **执行裁剪脚本**
   - 运行 `bash skills/linkgame-cropper/linkgame-cropper.sh [目标路径]`
   - 脚本行为：
     - 自动检测 ImageMagick，未安装则通过 Homebrew 安装
     - 跳过已裁剪过的文件（文件名含 `64@1x` / `64@2x` / `64@3x` 后缀）
     - 对每张原始图片生成三个尺寸版本

3. **确认结果**
   - 输出生成的图片文件列表
   - 如有文件处理失败，提示用户手动排查
