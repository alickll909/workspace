# glm-vision-mcp-server

智谱AI GLM 视觉理解 MCP 服务器，支持 GLM-5V-Turbo、GLM-4.6V 等模型。

## 用途

图片理解、图像分析、视觉问答：
- 识别图片中的内容、文字、图表
- UI 截图还原分析
- 图片 OCR 文字提取
- 图像场景理解

## 使用方式

```bash
npx glm-vision-mcp-server
```

## 前置要求

- 已安装 `glm-vision-mcp-server`（`npm install -g glm-vision-mcp-server`）
- 环境变量 `ZHIPU_API_KEY` 已设置
